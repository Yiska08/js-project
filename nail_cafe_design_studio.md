# Nail & Sip: Nail Design Studio

Build a command-line application where users create custom nail designs and organize their creations in a personal gallery.

## Step 1 — Create a Nail Design
- Choose a nail type (classic polish, gel, or acrylic), shape, and base color.
- Display a summary of the design and its price.
- Allow the user to start over or exit.

## Step 2 — Add Customization
- Add patterns and accessories such as glitter, bows, gems, and stickers.
- Allow multiple accessories and let users remove selections.
- Update the design summary and total price as choices change.

## Step 3 — Build a Design Collection
- Give each design a name and save it to a collection.
- List, view, edit, duplicate, and delete designs.
- Let users select an existing design to customize further.

## Step 4 — Organize the Gallery
- Tag designs with themes such as Coquette, Gothic, or Minimalist.
- Browse designs by theme and search by name or color.
- Display a compact gallery of saved designs and their pairings.

## Step 5 — Save Progress
- Save the design collection to a JSON file.
- Load saved designs when the application starts.
- Handle missing or invalid save files without crashing.
